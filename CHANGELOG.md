# Changelog

What changed in each version, for people using Snapback. The newest version is first.

## 0.1.0

The first release.

- Save the open windows as setups and switch between them from the bar. Undo a switch with
  **Before switch**.
- Windows come back on their screens and workspaces, with tiled layouts rebuilt, workspace layouts
  (tiling, scrolling, floating), floating, full screen and full width windows.
- Browser tabs per window for Chromium, Google Chrome and Brave; web apps; terminals in their
  folders, each as the terminal it was.
- Works on one screen or three: screens are matched by make, model and serial, or by role
  somewhere else.
- Restore at login, with the desk saved as you work.
- Pinned windows and apps never reopened (Zoom by default) stay open through a switch.
